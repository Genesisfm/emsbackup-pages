EMSBackup Privacy Policy

Last updated: 28 October 2026

Purpose and scope

EMSBackup is a personal tool for securely backing up an energy management system database to the owner's Google Drive account using rclone. It is not a publicly offered service.

Data accessed

With the owner's authorization, the tool can use Google Drive permissions to list, upload, download, and delete files as needed for backup, retention, and recovery tests. The requested permissions may technically allow access to other Drive files, but the configured backup process targets the owner's designated backup directory.

Storage and security

Database backup files are encrypted locally by rclone crypt before uploading to Google Drive. OAuth credentials and encryption configuration are stored on the owner's private server, not in this website. Google Drive stores the encrypted backup files according to the owner's Google account settings.

Sharing and use

EMSBackup does not sell personal data, use it for advertising, or intentionally share it with third parties. Data is processed through Google Drive for the backup functionality, and this public information site is hosted by GitHub Pages. Those providers may process technical usage information under their own policies.

Retention and deletion

The backup process is configured to retain a limited number of daily and weekly backup versions and remove older versions. The owner can revoke OAuth access in their Google account, remove the application configuration, and delete stored backup files from Google Drive.

Contact

Questions about this personal application may be addressed through its GitHub repository.
