EMSBackup

EMSBackup is a personal utility that backs up a private energy management system (EMS) SQLite database to the owner's Google Drive using rclone.

How it works

The backup runs on a private server. Backup files are encrypted locally before being transferred to Google Drive. The application uses OAuth authorization to access the account selected by the owner and to maintain its backup retention policy.

EMSBackup is intended solely for the owner's personal use. It does not offer accounts or services to the general public.

Google Drive permissions

The application requests Google Drive access to upload, list, retrieve, and delete backup files. Because the existing backup destination must be preserved, it may request the broad Google Drive scope. These permissions are used only for the owner's backup workflow.

For more information, see the privacy policy.
